# Minecraft 統合版 ハードコア荒らし対策アドオン（Hardcore Guard）

Minecraft Bedrock Edition（統合版：Windows ローカルマルチおよび Realms）の**純正ハードコア環境（チート無効設定）**で稼働する、危険物監視・監査ログ記録・インベントリ検査・高速追放（Kick / 永久追放引き継ぎ）アドオンです。

> **開発背景・生成について**
> 本リポジトリのソースコード一式（Behavior Pack / Resource Pack / パッケージングスクリプト / 手動確認テストシート）は、設計仕様書（[`指示書.md`](./指示書.md) / [`HARDCORE_GUARD_SPEC.md`](./HARDCORE_GUARD_SPEC.md)）を **Google Antigravity** に読み込ませて自動生成し、実機（ハードコア・マルチプレイ環境）での動作確認とフィードバックを通じてブラッシュアップしたものです。

---

## 主な機能

1. **右上サイドバー常時表示（JSON UI 非改変）**
   - スコアボードサイドバーと独自ドット絵フォント（`glyph_E1.png`）を組み合わせ、本体アップデートで画面が破損しない安全な方式で常時表示します。
   - **最上段ヘッダ**: 累計戦没者数（ドクロアイコン＋死者数）
   - **危険物所持数**: オンライン生存プレイヤー全員の「マグマ・火薬箱（TNT）・火薬車（TNT付きトロッコ）・結晶（エンドクリスタル）・アンカー（リスポーンアンカー）」の合計所持数をリアルタイム集計

2. **危険物の入手・使用・設置・コンテナ出し入れ監視（完全日本語表示）**
   - **最優先危険物（Tier 1）**: マグマバケツ、火薬ブロック（TNT）、TNT付きトロッコ、エンドクリスタル、リスポーンアンカーの所持数増加・使用・設置を検知し、警告音とともに全体チャット通知＆監査ログ記録を行います。
   - **警戒対象物（Tier 2）**: ディスペンサー（設置および開操作）、火打石と打ち金、ファイヤーチャージ、粉雪入りバケツ、ウィザースケルトンの頭蓋骨の使用・設置を検知・記録します。
   - **コンテナ出し入れ差分（`CONT_DIFF`）**: チェストやディスペンサー等の開閉前後のアイテム増減を追跡し、全バニラアイテム対応の日本語辞書（`ja_dict.js`）により日本語アイテム名で監査ログへ記録します。

3. **管理者端末（`hc_guard:op_terminal`）と2段階高速起動**
   - ワールド初回入室者を「最高管理者」として自動登録し、インベントリ固定属性付きの「管理者端末」を自動配布します（最高管理者は他の参加者を「副管理者（協力者）」に任命・解任可能）。
   - **通常使用（非スニーク）**: 管理者メインメニューを開く
   - **スニーク使用（しゃがみ状態）**: メインメニューをスキップし、最速で **「緊急一括追放画面」** を直接起動

4. **参加者持ち物検査・単発追放・ワールド跨ぎ永久追放（BAN引き継ぎ）**
   - オンライン参加者のインベントリ（36枠＋オフハンド）を一覧検査し、詳細画面から1クリックで「単発追放」または「永久追放」を実行できます。
   - ハードコアでワールドを作り直す際も、「追放済み一覧・永久追放引き継ぎ」画面から追放リスト文字列をコピー＆貼り付け取り込みすることで、新ワールドへ永久追放リストをそのまま引き継げます（再接続時に新ワールドの識別番号を自動紐付けして即座に追放）。

5. **戦没者一覧・ドクロ数カウント除外管理**
   - ハードコアでのプレイヤー死亡時に座標・ディメンション・日本語の死因を全体通知＆記録します。
   - 荒らしの自滅など、累計死者数（ドクロ数）に含めたくない死亡記録は、戦没者一覧画面からクリック1つでカウント除外／対象を切り替えられます。

6. **透過（X-Ray）リソースパック対策**
   - ビヘイビアーパックとリソースパックに相互依存（UUID）を設定しています。ワールド設定で「参加するにはリソースパックの同意が必要」を有効化することで、参加者側の透過リソースパック等の適用を防止できます。

## 導入方法

1. 本リポジトリ右側の **「Releases（リリース）」** から最新の `hardcore_guard.mcaddon` をダウンロードし、ダブルクリックして Minecraft 統合版へインポートします。
2. 対象ワールド（または新規ハードコアワールド）の設定を開きます：
   - **ビヘイビアーパック**: 「ハードコア荒らし対策（動作パック）」を有効化
   - **リソースパック**: 「ハードコア荒らし対策（リソースパック）」を有効化し、**「参加するにはリソースパックの同意が必要」** にチェックを入れる
3. ワールドを開始すると、最初に入室したプレイヤー（ホスト）が自動的に「最高管理者」として登録され、インベントリに「管理者端末」が配布されます。

## 再ビルド手順（開発者向け）

ソースコードやアセットを編集した後、PowerShell で以下のスクリプトを実行すると、PNG ヘッダ検証・JSON 構文検証・ES Module `import` パス検証を行った上で `hardcore_guard.mcaddon` を再生成します。

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\build_mcaddon.ps1
```
